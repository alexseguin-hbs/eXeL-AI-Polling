## 5. NOSE statements to drop into S3 / appendix

### Utility / Industrial
- **Need:** Restore service and protect the surrounding community while GridOS does restoration math.
- **Outcome:** Fewer unmanaged community failures during an already-counted SAIDI event (shelter, medical devices, fuel, access).
- **Solution:** DRS coordination layer beside GridOS, not inside the OMS.
- **Evidence required:** time-to-assign non-grid resource; unresolved shortages; plan-revision latency; official acknowledgement rate.

### Healthcare / regional
- **Need:** Coordinate capacity and public guidance across facilities and jurisdictions without amplifying panic.
- **Outcome:** Faster multi-org picture; fewer conflicting public messages; auditable authority.
- **Solution:** Inter-organization + population layer around Veoci/HICS.
- **Evidence required:** time-to-common-picture across orgs; public-message version count; volunteer qualification cycle time. Diversion only if clinician-endorsed.

### Campus / fixed site
- **Need:** Account for a known population and fulfill welfare / shelter / supply needs, not only notify them.
- **Outcome:** Minutes-to-accounted-for; minutes-to-sheltered; supplies issued vs requested.
- **Solution:** Resource layer beside Sentinel alerts / video rooms.
- **Evidence required:** accountability completion; need→fulfillment time; duplicate labor hours; drill vs live gap.
