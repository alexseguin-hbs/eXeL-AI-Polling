# For Grok: Sensor Fusion on a phone held sideways — the label dock covers the whole pane (methods, not code)

**What a user sees (844 × 390, phone landscape).** The labeler pane is 252 px tall. The sticky `.labelDock`
(`position: sticky; bottom: 0`) is 360 px tall, so it covers the entire pane. The picture, the Label name field,
"Box numbers" and the rows cannot be uncovered. Portrait (390 × 844) is fine: the dock is 263 of 706 px.

**Why.** The rev-43 landscape rule (`@media (orientation: landscape) and (max-height:520px) { .labelDock { display:flex } }`)
was written for the buttons and the last note only. The dock has since gained workLine (658e7c3), swarm (5c70317) and
metrics (ecc547d). In one row, each of those becomes a narrow column (rule 356 px, note 210, metrics 186, workLine 109,
swarm 101). **ecc547d** ("Show Level 1 and Level 2 counts") pushed the dock past the pane height. This was found by a
real-build bisect: 493ede8 good, ecc547d bad.

**The method (file `frontend/app/SensorFusion-2525/sensor-fusion.tsx`, around lines 1140-1172):** keep only the buttons
and the last note inside the sticky dock, as rev 43 intended. Move workLine, metrics, swarm and the rule text just above
the dock, where they scroll with the pane. Put the rule text ABOVE the dock, not below it: below breaks
`tests/sensor-fusion-glass.test.mjs:50`, which expects the dock to be followed directly by `{pic && (marks`.
A CSS-only wrap still leaves the dock at about 150 px, which cannot fit beside a 170 px picture in a 252 px pane.
Hiding lines would remove UI.

**Proof the method works** (scratch build of 802bf0c, fix applied):
- `scripts/sf-layout-smoke.mjs` went from `18 passed, 1 failed` (crash: `.labelDock intercepts pointer events`) to `27 passed`.
- Other SF gates stayed green: glass 24, labeler 26, coral 44, capture 39, info 49, labels 28, r4a 26, voc 15.

**Before you push:** run `cd frontend && npm run build:parity` (8 s), then `npx next build && node scripts/sf-layout-smoke.mjs`.
The rule text moving above the buttons is a visible change; check it with the operator.
