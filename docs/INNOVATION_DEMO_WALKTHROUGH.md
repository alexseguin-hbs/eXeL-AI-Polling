## 1 · Portfolio (the decision surface)
- **Growth Model** on top — orange **Incremental = New − Decline + EOL** (toggle each band; decline reads negative);
  grey baseline revenue is set at **BU · SBU · Alpha Group** in Admin.
- **Rack & Stack** table — switch the level toggle: **SBU** rows nest under a **BU** header; **Alpha Group** rows
  nest under an **SBU** header; drag priority across the amber **funding line**.
- **Dependency Constellations** — force-directed graph, drag / zoom / pan, colour-by-division.

## 2 · Open a project → the digital deck
Click a project → **▶ Present**. Each slide is a full-screen stage:
- Header: `gate · stage` (cyan, left) · **optimized title** (centre, flips with As-set / HI / AI) · slide code (right);
  amber **Req: `<stage>`+** badge upper-left, on the controls line.
- Flip **As set / 웃 HI / ◬ AI** to show the human baseline vs the AI superset — every field, live.
- **S2 · Project Overview** shows the **Program timeline** — the **MoT gate schedule** G1→G7 with estimated dates.
- **S3 · Financial** — cash chart with **Chart / Table** toggle (Revenue · Margin · R&D/NRE · Cash flow × year).
- **S4 / S6 · CONOPS** — each step renders a **generative wireframe** schematic (procedural, deterministic).
- Every chart/table maximizes (⤢) to full screen and restores (⤡ / Esc).

## 3 · Single source of truth (real-time)
- Every financial / resource card carries **◈ Edit source →**. Click it → jumps to the **one** source record
  (R&D/NRE, revenue, do-nothing, confidence, risk, upside accel, **Program start**).
- Change **R&D / NRE** → every chart, KPI and roll-up updates. Change **Program start** → **every gate date slides**
  (MoT framework). No duplicate sources anywhere.

## 4 · Gate governance — CS + RA
At the end of each gate review, two closeout slides resolve from **live governance data**:
- **CS · Change Summary** — version + approval history (audit trail).
- **RA · Review & Approvals** — board sign-off with approver **title + name**, ≥10% quantified change routes to
  the Lead for click-approval + tri-lens (Engineering / Commercial / Business) notify.

## 5 · Edit from a slide → instant save → back live
In Present, tap **✎ Edit** → land on that slide's inputs → edit HI or AI → it saves and shows back in the deck
immediately. Per-slide **version history** is replayable gate-to-gate with comments.
