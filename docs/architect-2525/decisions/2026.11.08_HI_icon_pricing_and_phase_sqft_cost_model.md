# H.I. clarification — ICON wall-system pricing + per-phase $/ft² cost model (2026-11-08)

> PERSIST-FIRST addendum to `2026.11.08_HI_live_product_bom_ruling.md`. The base ruling is sha256-frozen; these are the
> operator's later binding clarifications of the same day, preserved verbatim. They refine the cost architecture; they do
> not change the base product decisions.

## 1 · ICON figures are WALL-SYSTEM references ONLY
The $34 / $35 / $25 / $20 per-ft² figures and the R-22 / fire / wind / termite / mold / flood values are **ICON cement
3D-printed wall-system targets/references only** — nothing more. They are NOT whole-house costs, NOT whole-building
qualification, and NOT inputs to the whole project estimate by themselves. They establish none of: total house cost,
total project cost, whole-building qualification/energy/fire/wind/flood, the $240,000 baseline, or any arithmetic relation
to $240,000.

## 2 · Corrected wall-system benchmark table (locked)
These live on a dedicated **wall-system comparison surface**, each labelled by authority:

|---|---|---|
| Conventional industry reference | ≈ $34 / wall ft² | REFERENCE (standard industry) |
| ICON Phoenix | ≈ $25 / wall ft² | HISTORICAL REFERENCE |
| ICON Titan | **$20 / wall ft²** | TITAN TARGET / REFERENCE |

- **Titan is locked at $20 / wall ft² — a single target, never a range.** Do NOT render "$20–$25". ($25 is Phoenix's
  historical generation; $20 is Titan's current target.)
- Standard industry wall system ≈ $34/ft²; ICON Titan is now $20/ft² (Phoenix was ~$25).

## 3 · Benchmark separation (unchanged, reinforced)
Never visually or mathematically imply `$34/wall ft² × house area = $240,000`, or `$20/wall ft² Titan = total project
cost`, or `ICON wall-system target = whole-house estimate`. The wall-system metric applies to the relevant wall-system
scope only. If the project uses a printed cement wall system, the applicable wall-system reference may be ONE evidenced
input/comparison point for the wall-system BOM — never the source of the whole project estimate. The authoritative
whole-project estimate always rolls up: BOM line → assembly → system → phase → total project estimate.

## 4 · Ratings qualification rule (unchanged)
R-22 / fire / wind / termite / mold / flood remain wall-system REFERENCE/TARGET until the actual Architect-2525 project
carries project-specific evidence that the installed wall system meets them. A wall-system reference never auto-qualifies
the whole house.

## 5 · NEW — every building element gets a $/ft² estimate WITH ERROR BARS, per phase
Operator 2026-11-08: "all building elements get $/sq foot estimate with error bars … you need ranges from BOMs AND
take-offs to calc/update price per square foot (a USA standard), more to calculate margin. all details must roll up
accordingly."

### The 11 canonical build phases (locked order)
1. Foundation · 2. Framing · 3. Roof · 4. Plumbing · 5. Sewer · 6. Electrical · 7. Air Flow · 8. Internet · 9. Security ·
10. Insulation · 11. Finish

### Rule
- **Every phase (and every building element within it) carries a $/ft² estimate WITH ERROR BARS (a low–high range)**, not
  a single point — the USA-standard way to express a build cost before quotes firm it up.
- The range is **derived from the BOMs AND take-offs** (quantities × unit-price ranges + labor/equipment), so a geometry
  or design change updates the quantities, which updates the $/ft² range, which rolls up. Not a hand-maintained number.
- **Margin** is calculated on top (a separate, labelled line), from the ranged subtotal.
- **All details roll up accordingly**: element → assembly → phase ($/ft² range) → whole-project estimate ($/ft² range +
  total, with its error bars), every level explainable down to its BOM/take-off lines and rolling up deterministically.
- $/ft² is computed against the canonical area (per-phase against the relevant area; whole-project against the 900 ft²
  clear / 1,296 ft² gross as appropriate, each labelled which basis it uses).
- Evidence/authority labels still apply to every priced line (SUPPLIER_QUOTE … UNPRICED); UNPRICED contributes null (not
  $0) and shows in coverage; the error bar widens where evidence is weaker.

### Folds into R3 (the BOM cost engine)
This is the shape of R3's roll-up: the hierarchy gains an explicit **per-phase $/ft² range + margin**, with the 11 phases
as the phase layer. The legacy $240,000 ten-row model stays a reference/variance baseline; the ICON wall-system table (§2)
is a wall-system comparison surface, never the project total.
