## The trap, recorded because it is the third of its kind this session

The `88vh` leg first matched **its own explanatory comment** — the note above the style block names the old
geometry deliberately. It now strips comment lines before reading, and was re-proved able to fail afterwards
(3 red on the old panel, 0 on the new). The earlier two were the serialisation needle counting its own string
literal, and a boot leg that passed because the listener it tested had not been registered yet. Same lesson each
time: **a check that can see its own text is not checking anything.**
