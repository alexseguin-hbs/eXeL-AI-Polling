## The false pass this revision found in a leg I had just written

The first cut of the lock-held leg lived in `MOUSELOOK_LEAVES_THE_TOUCH_PATH_ALONE`, inside `toolSelfTest`. It read
green — **and it was measuring nothing.** `toolSelfTest` runs synchronously at boot, long before the mouse-look IIFE
registers its window listeners, so "with the lock held a finger fires nothing" passed *because nothing was
listening*. A gate that cannot fail is not a gate, and this one could not even be reached.

The legs that need a live listener are therefore in a **deferred** row, `MOUSE_LOOK_LEAVES_NO_TRACE`, on the same
`setTimeout` pattern r.209 and r.210 already use. Proof it now measures something real: S1 turns it red.

A second self-inflicted trap, worth recording because it took two attempts: leg (d) asserts the self-check
serialises the document once, and its first two forms **counted their own text** — the comment above the hoist, and
then the assertion's own string literal. The needle is now assembled from pieces (`'='+'document.documentElement'+…`)
so the line cannot match itself.
