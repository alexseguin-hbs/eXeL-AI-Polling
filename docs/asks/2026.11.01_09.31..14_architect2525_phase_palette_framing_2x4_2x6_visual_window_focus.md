   construction phase is selected, the palette is that phase's menu — not the furniture menu.
2. **Framing shows 2×4 and 2×6.** The framing phase's menu is the stud members — 2×4 and 2×6 — not Sleep/Bath/Living
   furniture. (Consistent with his earlier phase-layers ask: "framing should just show 2x4 and 2x6".)

   phase go away — the clutter is removed.
4. **The visual window is the key focus (Security-2525 pattern).** The model view is the hero of the screen, the way the
   Mission-Planning map is in Security-2525; every menu is a slim SUPPORTING control around it, not competing with it.

## The build (R-PAL1) — modular, one source for the phase→palette mapping
- **`lib/architect-phase-palette.ts` (NEW, pure, gated)** — the ONE source:
  - `phasePaletteMode(phaseId)` → `furniture` (no phase / Interior Design — the full palette, unchanged) · `framing`
    (the 2×4 / 2×6 stud selector) · `fixtures` (Plumbing/Sewer — the Bath + Kitchen fixtures the phase serves) ·
    `openings` (Finish — doors/windows set in the framed openings) · `none` (every other construction phase — the model
    is the focus; a one-line note names the phase's work).
  - `phaseAllowedGroups(mode)` → which furniture `AssetGroup`s the palette may show (`"all"` · `["Kitchen","Bath"]` ·
    `["Openings"]` · `[]`). The furniture source stays `groupPalette(paletteForRoom(room.k))` — this only FILTERS it.
  - `STUD_GAUGES` — the framing members the operator named: `2×4` (actual 1.5"×3.5") and `2×6` (1.5"×5.5"),
    framed at `STUD_SPACING_IN = 16"` on-centre; `DEFAULT_STUD_GAUGE = "2x6"` (exterior / load-bearing).
  - `studSkeleton(sideFt, gauge)` — the stud layout for the 10-ft room at 16" o.c. in the 0..100 plan viewBox (one
    member tick per stud along each of the four walls; member depth reads deeper for 2×6 than 2×4). Pure + deterministic.
- **`room-designer.tsx`** — `paletteEl` becomes phase-aware off `phasePaletteMode(phase)`: Framing → the **2×4 / 2×6**
  selector (persisted `arch2525.studGauge`), no furniture; Plumbing/Sewer → Bath + Kitchen only; Finish → Openings only;
  other construction phases → a slim supporting note (no furniture buttons); no phase / Interior Design → the full
  palette (unchanged). `plan2D` draws the **stud skeleton** (studSkeleton at the chosen gauge) when Framing is selected,
  so the visual window shows the framing — the key focus. Removing the furniture menus declutters the screen so the model
  is the hero (his "visual window is key focus · all other menus support this").
- **Gate** `tests/architect-phase-palette.test.mjs` (test:ci + ci-wiring): the pure mapping (framing→framing,
  plumbing/sewer→fixtures, finish→openings, foundation/roofing/electrical→none, null/interior→furniture); the allowed
  groups per mode; STUD_GAUGES (2×4 3.5" · 2×6 5.5" · default 2×6 · 16" o.c.); studSkeleton determinism + every stud
  inside the room + 2×6 deeper than 2×4; source regexes on room-designer.tsx (imports phasePaletteMode, the framing
  gauge selector `data-arch-framing-gauge`, the stud skeleton `data-arch-framing-studs`, the palette filtered by
  phaseAllowedGroups).
