## 3. How to bring the icons in
1. **Draw them as icons, not pictures.** Redraw the six as simple stroke shapes (SVG) in the page's own colour, so they stay sharp
   on every screen, follow the theme, and weigh almost nothing. The existing PNGs in `frontend/public/sensor-fusion/ui/`
   (`capture_images_001.png`, `train_model_001.png`, `models_icon_001.png`) are the older set; keep them until the new set ships,
   then retire them in one change.
2. **One file holds all six** (for example `frontend/app/SensorFusion-2525/steps.ts`: id, label, short line, icon), read by the
   buttons, the step strip and the Python program's menu text — one list, not three.
3. **Words under each icon stay short** (the original titles). The longer line from the original image appears as the help text.
4. **The original says "45–60 second video".** At the sensor, "How many" can offer that as a choice: record 45–60 s, keep one frame
   every N (e.g. every 0.5 s → 90–120 pictures), named by the never-repeat rule.
5. **The Python program** prints the same six steps on its menu (menu 4 Capture · Annotate, menu 8/9 Save set · Upload).
6. **Credit.** The six icons come from the original De-Risking Strategies training material; keep them in that family (same teal,
   same rounded strokes).
