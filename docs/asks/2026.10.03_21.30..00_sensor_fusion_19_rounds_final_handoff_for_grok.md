## Ten learnings that held across the rounds
1. **Read the code first.** Stale citations recurred every round. A citations test (`sensor-fusion-plan-citations.test.mjs`) keeps the plan honest.
2. **Security before features.** Closing guest read and insert (R4a, migration 042) was right to go first. It is shipped; it needs applying in Supabase.
3. **Do not wait on hardware.** Loops take detections from today's models (`cnn.js`, `sensor_fusion_edge.py`); DETECT feeds the same record later.
4. **One record, one spec, two runtimes.** Page and Python read the same files and pass the same golden vectors. Never three copies.
5. **Time in milliseconds, and command rate is not frame rate.** Air proposes 50 Hz commands, so jitter must be measured (`linkJitterP99Ms`).
6. **Clear is not broken.** A zero-object heartbeat means clear. A frozen camera has its own pass line: slow first, then the safe action.
7. **No failure maps to "continue".** Air hovers, lands or returns; water holds or surfaces; ground stops with the brake held.
8. **Simulation, then shadow, then bench, then a fenced field.** Each stage is signed. A live loop refuses an unsigned or mismatched card.
9. **One CNN, many places, with clear limits.** Robots, EdTech cameras and computers share models. Cameras only alert. No face
   recognition, faces blurred, consent recorded, alerts to named staff.
10. **The boundary held all 19 rounds.** Targeting means goal targeting. The turret has no loop. A detection steers, slows, holds or
    stops; it never marks, approves or fires.
