**Permanent doctrine:** Actual time stays time. Trade multiple expresses qualified labor value. 웃 expresses recognition.
Local wage expresses local settlement basis. Project cost remains project cost. Do not let one impersonate another.

1. **CANONICAL 웃 FORMULA.** 1 웃 (base) = 1 hour at 1× the contributor's local minimum-wage value. M = the multiple
   applied to qualified contribution. 웃 earned = M × actual hours. (100 h × 4× = 400 웃; 4,060 h × 4× = 16,240 웃.) Never
   display raw hours as 웃 when M ≠ 1. Actual elapsed time stays separately recorded.
2. **RECOGNITION GLOBAL · SETTLEMENT LOCAL.** Same hours + same M = same 웃 across jurisdictions. Changing jurisdiction
   may change local wage basis / native-currency settlement reference / informational FX; it must NOT change earned 웃 /
   trade classification / actual hours. Do not rank workers by USD conversion. USD is informational only.
3. **TRADE MULTIPLE M IS DERIVED, NOT FROZEN.** M_trade = researched U.S. trade reference rate ÷ U.S. base minimum-wage
   reference (e.g. $29 / $7.25 = 4.0× — example only). Store M as DERIVED with occupation · source set · geography ·
   source vintage · chosen statistic · derivation. A computed M is not a canonical whitepaper trade band.
4. **RESEARCH TRADE RATES BEFORE DERIVING M.** Prefer official wage sources; documented median/trimmed average across
   comparable sources; never average incompatible quantities (bare wage vs loaded cost vs billing rate vs quote) without
   normalizing; each stored rate identifies its type; no defensible rate → NOT CALCULATED (never invent a rate).
5. **TASK → TRADE → HOURS → M → 웃 RECOGNITION**, then SEPARATELY **PROJECT REGION WAGE/QUOTE → PROJECT LABOR COST.**
   No invented hours; missing hours → LABOR HOURS · NOT CALCULATED, 웃 · NOT CALCULATED.
6. **PROJECT COST IS A DIFFERENT DOMAIN (the firewall).** The comparison headline is construction cost. It changes ONLY
   from construction-cost evidence (accepted vendor quote · stored project-region wage row · verified prevailing/local
   trade rate · approved material price · approved markup · approved schedule/labor-hour change). It does NOT change when
   the user changes the 웃 multiple display / settlement jurisdiction / FX / 4.807 reference / 9,999 boundary / foreign
   min-wage example. A settlement comparison is not a house-cost mutation.
