## The directive (verbatim)
> "when phase is selected; interior elements go away:
> framing should just show 2x4 and 2x6
> plumbing shows piping fittings and valves
> electrical shows junctions; breakers, wiring , plugs, conduit if any"

## What it means (MoT reading)
On the DESIGN MODEL whole-house plan, selecting a construction phase must DROP the interior/furniture and show ONLY that
phase's layer:
- **Framing** → the 2×4 / 2×6 stud skeleton only (no furniture).
- **Plumbing** → pipe runs + fittings + valves.
- **Electrical** → junctions, breakers, wiring, plugs, conduit (if any).
- **Sewer** → DWV runs + traps + fixtures.
- (Foundation → slab/footings; Roofing → trusses/shell; Insulation → envelope; Finish → surfaces; Interior Design →
  the furniture layer — the ONE phase that shows furniture.)

## The gap (measured)
`phaseDraw(phase)` (lib/architect-phases.ts — mep/structure/openings/fixtures/furniture flags per phase) is applied in the
SINGLE-ROOM designer (room-designer.tsx:81) but NOT in the whole-house plan the operator is viewing:
tiny-floorplan.tsx (has `showFurniture` default true, no phase) and voxel-house.tsx (`roomCubes` draws objects
unconditionally). So the whole-house Design Model always shows furniture regardless of the selected phase.

## The fix (two parts)
1. **Interior goes away (the core):** thread the active `phase` into the whole-house plan (TinyFloorplan + VoxelHouse) and
   derive `showFurniture = phaseDraw(phase).furniture` — furniture hides for every construction phase, shows only on
   Interior Design (or no phase). Immediate, high-value, matches "interior elements go away."
2. **Draw each phase's layer components** (the richer piece): framing studs (2×4/2×6 @16" o.c.), plumbing pipe+fittings+
   valves, electrical junctions/breakers/wiring/plugs/conduit, sewer DWV+traps — at the whole-house scale (extend
   mep-runs.ts which already draws water/sewer/wiring runs; add the framing stud layer + the fittings/valves/junction
   components). Each gated; the all-numerics + one-source laws hold (counts come from the one geometry, as R-TO1).

## Execution
Part 1 shipped as a focused gated revision now (production-always). Part 2 (the component drawing) folds into the fleet
design + the batch. Gate: the whole-house plan hides furniture when a construction phase is active, shows it on Interior
Design — one source (phaseDraw), consistent with the single-room designer.
