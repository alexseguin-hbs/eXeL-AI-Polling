## What we learned (ten lessons)
1. **The goal was missing from the plan.** v3 stopped at a training JSON and a box on a screen. The operator's goal is detection inside the
   control loops of Drone-2525, Manta-2525 and MASS-AI. Round 1 added Part C for that.
2. **Read the code before planning.** R1 (one `models.json`) had already shipped. Several citations were stale. Rule now: every
   `file:line` is re-checked each round, with a citation test.
3. **Security first.** Guests can **read and insert** pictures and labels today (migrations 040/041). A poisoned label set becomes a
   vehicle that steers wrong. Closing that (R4a) ships before any group feature.
4. **Do not wait on hardware.** Part C first depended on the DETECT cable, which does not exist. Now loops take detections from the model
   that runs today (`cnn.js` in the browser, `sensor_fusion_edge.py` on a vehicle). DETECT feeds the same record later.
5. **One record, one spec, two runtimes.** One versioned Detection record (`lib/2525-core/detect-contract.ts`) and one
   `public/sensor-fusion/loop-spec.json` read by both TypeScript and Python, proven by shared golden vectors. Never three copies.
6. **Time in milliseconds, not frames.** Three frames at 4 fps is 750 ms against a 250 ms budget. Every age limit is in ms from the capture stamp.
7. **"Clear" is not "broken".** A zero-object heartbeat means the sky is clear. Silence means the detector is lost → safe action.
   Otherwise a pilot learns to ignore warnings.
8. **No failure maps to "continue".** Air: hover, land, return. Water: hold station, surface. Ground: stop. The human takes over within one tick.
9. **Be honest about worlds.** Only the turret and the VTOL quad-wing exist in code (`controls.ts:19`). Manta and MASS-AI are
   **replay-ready**, never **loop-ready**, until their worlds are built (decision 14).
10. **The boundary holds.** A detection steers, slows, holds or stops. It never marks, approves or fires. The Drone-2525 named-human
    TARGET → APPROVE → FIRE steps are untouched. Identity models (`checkid`) are never loop-eligible.
