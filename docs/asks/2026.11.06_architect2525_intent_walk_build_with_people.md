## THE FOUR PILLARS (end-to-end, one coherent journey)
1. **DESIGN** the house — the 3×3 of 10×10×10 inner rooms inside a 36×36×12 outer shell (900 ft², one storey;
   per-room 12-ft shell, the 2-ft plenum above the 10-ft ceiling carries ducts/roof/joists). The canonical cube.
2. **WALK THROUGH** it — first-person, phase by phase, seeing the REAL build at each phase (foundation → framing
   studs → electrical → plumbing w/ valves → HVAC ducts in the plenum → insulation → roofing → security → internet
   → interior → finish), with an overhead "where I am" beside the walk. You walk the house of your dreams.
3. **SEE STEP-BY-STEP BUILD INSTRUCTIONS** — while you walk a phase, you see HOW to build that phase: the measured,
   ordered steps (quantities, materials, members, sequence) so a real person can actually build it. The walk and the
   build instructions are ONE experience, not two tabs that don't talk.
4. **BUILD IT WITH PEOPLE** — family, friends, and professionals: share the design, invite feedback and help, assign
   who does what (roles), so the build is collaborative. The instructions speak to each (a friend vs a licensed pro).
