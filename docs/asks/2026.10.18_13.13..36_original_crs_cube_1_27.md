## 🧊 Cube 4 — User Input Aggregator (1,3,2)

**CRS-10** · WRS · `CRS-10.IN.WRS.010` · DR-2026.01.01-DR.001
*As the System, I want to cluster responses into meaningful themes using AI so large volumes of input become
understandable.*
- Target at Launch:
  > Classify every response into exactly one of three primary categories:
  >
  > Risk & Concerns
  > Supporting Comments
  > Neutral Comments
  >
  > Each classification includes confidence percentage (70–100%).
  > If confidence < 65%, automatically route to Neutral Comments.
  > After Theme1_3 classification, generate Theme2 sub-themes at three granularity levels
  > (Moderator-selectable):
  >
  > Theme2_9 (default): 9 distinct sub-themes per primary category
  > Theme2_6: reduced to 6 sub-themes
  > Theme2_3: reduced to 3 sub-themes
  >
  > Each sub-theme includes its own confidence percentage (70–100%).
  > Generate 333-word, 111-word, and 33-word summaries per response (translated to English if needed).
  > Use multi-provider abstraction (Gemini primary for multilingual, OpenAI fallback, Grok secondary).
- Stretch: Adaptive clustering with accuracy > 85% across 33 languages; live progressive Theme2 reveal for
  paid tiers; AI-suggested follow-up questions for deep dives.
- Output `CRS-10.OUT.WRS.010`:
  > Structured output includes:
  >
  > Theme1_3 category + Confidence %
  > Theme2_9 / Theme2_6 / Theme2_3 sub-themes (Moderator-selected level) with individual Confidence %
  > Exemplar responses per theme
  > Multi-level summaries (333/111/33 words)
  > All outputs are deterministic and reproducible (fixed random seeds, pinned model versions).

  and animations.
- Output `CRS-10.OUT.SRS.010` *(as written in the sheet)*:
