## 2. Spiral verdict

**Forward: fails.** The XML is what the training export will read. Today its boxes are rounded to whole percent first (`clampPct`). On a 4000 px photo that is a 40 px step. So Save set, Level 2 review and the next model would all carry that error. There is no Save set and no Open set yet. Boxes have no `level`, `labeled_by` or `labeled_at`. So reviewed boxes cannot reach a model folder.

**Backward: fails.** The Labeler is not given the open model, so it cannot read `labelmap.txt`. Picture names come from four patterns, and the same name repeats across sessions. Sizes fall back to 1. The 17.00 note is behind commit c42c24e:
- The four edge grips already exist. Do not rebuild them.
- Each grip is still centred on its line, so the finger covers it.
- The corner handles were removed.
