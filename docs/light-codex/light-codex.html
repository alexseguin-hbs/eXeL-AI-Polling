LIGHT CODEX

Double-helix colour-glyph encoding · canonical extended alphabet (collision-free) · one self-contained file. Colour order B R Y G C V W = Black, Red, Yellow, Green, Cyan, Violet, White. Every character is a 4-token group. Green (G) is reserved for the transmission frame (4=GGGG 3=GGGR 2=GGRR 1=GRRR). Signed as 4321 + message + 1234 forward, mirrored reversed.
