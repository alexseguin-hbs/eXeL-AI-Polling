§ 1

Recommended hierarchy D#1

The proposed stack is kept almost intact. One layer is added, none removed, none reordered. Resisting the urge to add more is itself a recommendation: every additional layer is a place for two documents to disagree, and this framework must stay legible for centuries.

  • Vision 2525
    Why the framework exists. Aspirational, amendable rarely, cited by everything.
  • Document 0 · Foundational Definitions & Boundaries
    What every word means. One ID per term. No governance, no obligations — definitions only.
  • Document 0.5 · Conformance & Inheritance Protocol
    Who may change a definition, what must pass before it changes, and how a downstream system proves it conforms.
  • Document 1 · Constitutional Specification
    Enduring governance. Slow to amend. Uses Document 0's words without redefining them.
  • Protective Charter
    Anti-capture, mission preservation, amendment resistance. Subordinate to the Constitution, superior to policy.
  • Operating Policies
    How the work is actually done. Freely amendable without touching anything above.
  • Regional Legal Implementations
    A conformance matrix, not a set of rewrites. See §5.

Why Document 0.5 exists, and why it is the one genuine gap

This project has already built a working inheritance contract — for geometry. docs/2525-core/WIREFRAME-CORE.md defines twelve shared primitives (U-WF-01…12) and then does the thing that makes them binding: a parallel development protocol stating that “a change to a U-WF primitive must pass BOTH domains' verification sheets,” with explicit pass criteria — determinism hash stable across five runs, render within the HAL budget, SSSES per pillar.

Document 0 as proposed has the definitions but none of that. It can be cited; it cannot be conformed to. The distance between those two words is the distance between a glossary and a foundation. WIREFRAME-CORE already proves the pattern works in this organisation — Document 0.5 is that same protocol, lifted from geometry to governance.

Confirmed — do not change The ordering is right. Every instinct to draft the Constitution first should be resisted, and §3 gives the evidence rather than the argument.

§ 2

Per-document purpose D#2

Decision required before drafting Document 0 should be a registry, not an essay. One entry per term: id · term · definition · boundary (what it is NOT) · supersedes · version. Prose renders from the registry; the registry is never derived from prose. This is the single highest-leverage choice in the whole hierarchy, because it determines whether a downstream system can check that it used a term correctly or merely claim it did.

A mechanism for exactly this already exists and is proven at scale: frontend/lib/lexicon-data.ts holds the app's key registry across the 33 supported languages (frontend/lib/constants.ts:53) with a documented fallback chain (translation → English default → raw key, frontend/lib/lexicon-context.tsx:182) and an admin approval gate. Document 0 should inherit that machinery rather than invent a second one.
DocumentOwnsMust never contain
Document 0Terms, boundaries, provenance of every constantObligations, rights, procedures. A definition that tells someone what to do is a smuggled law.
Document 0.5Change control, conformance tests, inheritance rulesDefinitions of its own. It governs terms; it does not create them.
ConstitutionEnduring principles, authority, amendment, continuityAnything with a number that will change — thresholds, rates, timelines, tooling.
Protective CharterAnti-capture, mission lock, transparency dutiesOperational procedure. It states what must remain true, not how a team works.
Operating PoliciesProcedure, workflow, engineering practice, finance opsAnything a jurisdiction could forbid. That belongs in Regional.
RegionalHow a jurisdiction satisfies each numbered obligationNew obligations. Regional implements; it never legislates upward.

Adopt the numbering that already exists

The repository already runs a disciplined citation scheme — CRS-##.## with .IN/.OUT identifiers, and domain-scoped variants U-WF-##, SEC-##.##, ARC-##.##. Governance clauses should join it as V25-##.##. Then a cube cites a constitutional clause exactly the way it already cites a requirement, and traceability comes free instead of being built twice.

Note that even the two that agree do not match: Shared Intent and Shared Intention are different words in a system that mints a token against one of them. This is not a hypothetical argument for Document 0 — it is the defect Document 0 exists to prevent, discovered in the framework's own foundation, and it settles the sequencing question on its own.

Second instance — found while verifying this review's own citations The supported-language count is stated two ways. The running code defines 33 languages (frontend/lib/constants.ts:53 — English included, and the lexicon derives from it). CLAUDE.md says “34 languages” four times and “33 languages” once, in the same file.

This one is trivial in consequence and precisely for that reason it is the more instructive finding. SI could be dismissed as three teams using a term loosely. A counted integer drifting against the code that produces it cannot. The defect is not carelessness about words — it is the absence of a single authoritative source with a version and an owner, which is exactly the hole Document 0 is proposed to fill. An earlier draft of this very review inherited the wrong number from CLAUDE.md without checking the code; that is how the defect propagates, and it is the argument for making Document 0 machine-readable (§2) rather than prose.

The test for which side a rule belongs on

A rule is constitutional if changing it would change who we are. It is operational if changing it would change how we work today. A practical proxy: if it contains a number that a competent team might tune next quarter, it is not constitutional. Under that test, qualification thresholds, moderation procedure, simulation rules, software lifecycle and financial operations all fall to policy — as proposed. That part of the split is correct as written.

§ 5

Universal vs jurisdiction-specific D#5

Recommendation: a Conformance Matrix, not a document per jurisdiction. Every jurisdiction implements the same numbered obligations; the matrix records how each one is satisfied locally, and only the matrix changes. Adding Brazil then means adding a column, not authoring a parallel legal document that can drift from the Constitution it claims to implement.

ObligationUSEUSGDIFCBR
V25-09.01 · entitlementuniversal — identical in every column, by construction
V25-09.02 · settlement—————
V25-03.01 · human authorityuniversal
V25-10.02 · data residency—————

Illustrative shape only — the cells are for counsel to fill, and this review does not attempt legal advice.

The property that matters: a row that is universal must be visibly universal. When a jurisdiction cannot satisfy a universal row, that is not a local exception to be quietly written down — it is a constitutional conflict that must escalate. A matrix makes that visible; five separate legal documents hide it.

§ 6

Economic architecture

The proposed chain — Participation → Contribution → Qualification → Responsibility → Capability → Compensation — is substantially more durable than organising around monetary contribution levels, and should be adopted. It separates showing up from being trusted from being paid, which is exactly the separation that keeps money from buying authority. Two refinements:

Insert Recognition between Contribution and Qualification

Contribution is what someone did; Qualification is a status the system grants. Without a step between, qualification has to do two jobs — acknowledging work and conferring standing — and those corrupt each other. Recognition is the record that a contribution happened and was accepted; qualification then reads the record. It also gives contributors something immediate that costs the framework nothing to grant honestly.

Split Compensation into Entitlement and Settlement

Already proven in this system The 웃 token was just re-founded on exactly this distinction. An hour of work earns 7.25 웃 anywhere on Earth — the entitlement, denominated in time, seeded from a minimum-wage floor and pegged to no currency. How that entitlement is settled — into which currency, under which tax and labour law — is jurisdiction-local. Before the change, a shipped SDK demo paid a Lagos hour 21× less than an Austin hour by “local rate”; the split is what made that impossible to express.

Carry that into the constitutional layer verbatim: entitlement is universal and belongs in the Constitution; settlement is local and belongs in the Regional matrix. This is the single strongest de-risking move available, because it stops jurisdiction-specific law from reaching upward into governance — the failure mode that makes international frameworks unamendable.

Shared infrastructure vs project-specific. The dividing line already used for geometry works here: a concept needed by two or more systems is defined once at the core and consumed; a concept needed by one stays local until a second needs it. Master of Thought — synthesis D#7 · D#8

The council converges on one finding and disagrees on almost nothing: the architecture is right and the enforcement is absent. Enlil's 72% is the lowest score and the most important — every other master's concern is a variation of it. Definitions that cannot be verified become suggestions; a hierarchy whose only binding force is good intention decays at exactly the rate that memory of the intention fades. That is the argument for Document 0.5, and it is the whole of this review's structural objection.

Long-term maintainability

The proposed hierarchy maintains well if and only if two properties hold: each layer is amendable without disturbing the one above it, and conformance is checkable rather than asserted. The first is designed for and mostly achieved — the leaks are Compensation (§6) and qualification thresholds (§4), both fixable now at no cost. The second does not currently exist at all.

The most encouraging signal is that this organisation has already solved the harder version of this problem once. WIREFRAME-CORE governs a shared substrate across parallel domains with a real change protocol and objective pass criteria, and it works. The governance stack is not attempting anything novel — it is attempting something already proven here, in a different medium. That is the strongest possible argument that it can be done, and the strongest possible argument for not inventing a second way to do it.

§ 12

Readiness D#10

Conditional GO. The framework is not ready to begin Document 0 today, and it is close. Nothing found in this review requires re-architecture; everything found requires a decision. Three exit criteria, each small, each genuinely blocking because each one changes what Document 0's first page looks like:

#Exit criterionWhy blocking
1Choose the canonical meaning of SI, and correct the two sources that disagreeDocument 0 cannot define a term the organisation has not decided. Everything downstream inherits the error.
2Decide Document 0's form — machine-readable registry, or proseDetermines whether conformance can ever be checked, and how every later document cites a term.
3Accept or reject Document 0.5 as a layerIf rejected, the Constitution must absorb change-control itself — a materially different Constitution.

Recommended once those clear, in order:

  1. Inventory every existing definition across the five prose sources and mark each supersede, merge or retire.
  2. Draft Document 0 as the registry, terms only, boundaries mandatory, provenance on every constant.
  3. Draft Document 0.5 against WIREFRAME-CORE's protocol as its stated antecedent.
  4. Only then open the Constitution — and when it uses a word, it cites a clause ID rather than explaining itself.
On the instinct that prompted this review Asking for an architectural review before drafting was correct, and it paid for itself: the review found a live three-way contradiction in the framework's most foundational term. Had Document 0 been drafted first, that contradiction would have been resolved silently, in one direction, by whoever happened to write the paragraph — and the Constitution would have been built on it. Care over speed. Define before governing.
