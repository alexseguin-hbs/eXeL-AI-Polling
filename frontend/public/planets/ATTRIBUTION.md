# Planet & Moon textures — attribution

Equirectangular surface maps used by the UCRS-2525 celestial map (Architect-2525
Design → Site → Solar System) and the Sky-Dome moon.

- **Source:** James Hastings-Trew — *Planet Texture Maps* (planetpixelemporium.com),
  redistributed via the `jeromeetienne/threex.planets` repository on GitHub.
- **Basis:** derived from public-domain NASA/USGS imagery.
- **Use:** free for personal and non-commercial use per the original author's terms;
  bundled here as local static assets (no external runtime fetch → offline, deterministic).

Files: `mercurymap.jpg`, `venusmap.jpg`, `earthmap1k.jpg`, `earthcloudmap.jpg`,
`marsmap1k.jpg`, `jupitermap.jpg`, `saturnmap.jpg`, `saturnringcolor.jpg`,
`uranusmap.jpg`, `neptunemap.jpg`, `plutomap1k.jpg`, `moonmap1k.jpg`, `sunmap.jpg`.

If this app moves to commercial distribution, replace these with fully-open
equivalents (e.g. NASA SVS / Solar System Scope CC-BY, USGS Astrogeology).
