# Architect-2525 · 3D asset library (runtime copy)

This folder is served at `/architect-2525/assets/…` and is the runtime's ONE asset library: the operator's **Architect-2525 Complete 10-Pack 3D Asset Library** (139 semantic assets — concept + library by **eXeL AI**; the repo master is `docs/architecture-2525/asset-library/3d-all-assets-2026-11-07/`, superseding the 18-GLB starter pack) copied VERBATIM in his layout: `manifest.json` (the registry — `{library, version, date, source, coordinateSystem, units, pivotConvention, …, assets[{id, label, packs, model, metadata, planSymbol, thumbnail}]}`), `models/<asset>.glb` (glTF 2.0 binary, **metres**, X width · Y depth · Z up, origin **floor-centre**, indexed triangles, materials with `baseColorFactor` — ONLY WOOD IS TAN), `metadata/<asset>.json` (his contract: packs · sections · sourcePlacementIds · dimensionsM · pivot · rotation · mounting · snap · authority · modelQuality · materialRule · rebuildSpec; validated here against `schemas/asset.schema.json`, the starter pack's schema), `plan/<asset>.svg` (top-down PLAN footprints), `inventory/placements.json` (the 148 board placements — the provenance ledger) and `docs/` (his `CLAUDE_CODE_INTAKE.md` + `VALIDATION.json`, the sha256 ledger every served model is pinned to). The only additions are ours: `thumbs/<asset>.png` (256×256 three-quarter isometric renders of each GLB through the runtime's own projector — never a drawing), each manifest row's `thumbnail`, the manifest's `source` note (the sha256 of his original manifest.json), this README and `schemas/`. His rule, honoured: **DO NOT REMODEL unless necessary — ingest, preserve ids, build the consumer.** The semantic id is law: a placement stores `assetId` + transform, never geometry; a rebuild or a higher-fidelity replacement keeps the id, the floor-centre pivot, metres, mounting/snap, the PLAN linkage and ILLUSTRATIVE authority — it replaces the file, never the id. Assets never touch canonical truth. Consumer: the pure in-repo reader (`lib/architect-2525/assets/gltf/glb-reader.ts`, node matrices applied) → model cache (`lib/architect-2525/assets/model-cache.ts`, one parse per id) → the existing SVG pinhole projector (`lib/solid-shade.ts` solidFaces) — no three.js; browser entry `lib/architect-2525/assets/index-runtime.ts` `loadAssetMeshFt(assetId)`. Rebuild path (when a rebuild is decided): `npm run assets:build -- --out <dir>` compiles `lib/architect-2525/assets/compositions/` through the pure GLB writer into his layout; `npm run assets:thumbs` renders the thumbnails. Gates: `npm run test:architect-asset-glb` (all 139) · `npm run test:architect-asset-glb-build`.
